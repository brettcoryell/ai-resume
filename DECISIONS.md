# Architecture Decisions — ai-resume

Brett Coryell's personal AI-powered career site. Recruiter-facing. Live at https://ai-resume-mu-seven.vercel.app.
Stack: React + Vite + TypeScript, Supabase (PostgreSQL + Edge Functions), Vercel, Anthropic Claude.

---

## Blob as source of truth

Decision: The `career_blob` table holds a single pre-compiled narrative of all OB thoughts tagged `ai-resume-source`. The chat Edge Function reads the blob directly as its system prompt context.

Why: Structured LLM extraction (breaking the career into tables of skills, accomplishments, etc.) is lossy and voice-flattening. Each extraction hop degrades fidelity and strips Brett's actual language. The blob preserves the raw narrative.

Violation looks like: Adding a new structured extraction step that reads the blob and populates a table with Claude-summarized fields. Or using LLM summarization to "clean up" OB content before it enters the blob.

---

## Voice preservation is primary

Decision: Biographical content in the OB and blob must be Brett's words (from Ariel sessions or dictation). Agents never create or rewrite biographical content.

Why: Brett's voice and specificity are the product. Generic AI-sounding language destroys the point of the site.

Violation looks like: Coda using `capture_thought` to fill a gap in the OB ("Brett worked at X from Y to Z"). Any agent-written content that describes Brett's career, personality, or experiences. Rewriting OB thoughts to "improve" them.

---

## View Context fields are curated and locked

Decision: The four Experience fields (Situation, Approach, Technical Work, Lessons Learned) should be written once by Brett/Ariel and stored as locked DB values. They are not regenerated by extraction on each blob rebuild.

Why: LLM extraction from the blob produces inconsistent, voice-flattened output on every run. Quality degrades unpredictably. Curated fields written by Brett/Ariel are the "wow" version.

Violation looks like: Triggering a rebuild-experiences run that overwrites curated field values. Auto-populating these fields from Claude extraction as a default path.

---

## Structured tables are display caches only

Decision: The `experiences`, `skills`, `candidate_profile` tables are display caches — populated from the blob or manually. They are not the source of truth for any content.

Why: The blob is the source of truth. Structured tables exist to make the UI fast and predictable, not to own the data.

Violation looks like: Editing a structured table directly to "fix" content without fixing the underlying OB thought. Treating `experiences.technical_work` as authoritative when it conflicts with the blob.

---

## Anon access requires both GRANT and RLS

Decision: Every table readable by the public requires both `GRANT SELECT TO anon` and an RLS policy. Neither alone is sufficient.

Why: PostgREST enforces GRANT before evaluating RLS. Missing GRANT = "permission denied" (hard failure). Missing RLS policy = silent empty result (invisible failure). Both are required.

Violation looks like: Adding an RLS policy without a matching GRANT. Wondering why anon reads return empty arrays when the policy looks correct.

---

## Chat uses Anthropic streaming

Decision: The chat Edge Function uses the Anthropic SDK (Claude Sonnet) with streaming. Not Gemini, not OpenAI.

Why: Anthropic streams with first tokens in 1–2 seconds. Gemini local-llm mode takes ~38s per question — unacceptable for recruiter-facing UX.

Violation looks like: Switching the chat endpoint to a different provider for cost reasons without re-validating latency against the recruiter use case.

---

## Test 5 canary is the regression gate

Decision: The 6-question canary test (`scripts/canary_test.py`) and the full 54-question Test 5 (`scripts/validate_pipeline.py --test 5`) are the acceptance criteria for any change that touches the blob, edge function, or OB content. Target: 94%+ pass rate.

Why: The pipeline has many hops and regressions are non-obvious. A change that looks fine in code can silently break answer quality.

Violation looks like: Declaring a blob rebuild or edge function change "done" without running at least the canary test. Merging to main without CI passing.
